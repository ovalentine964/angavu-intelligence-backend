## Architecture

**Rust (Axum)** = Primary backend — API, business logic, security, OODA loop
**Python** = LLM inference ONLY — DeepSeek, Qwen, XGBoost

```
OODAOrchestrator (Continuous Intelligence Loop)
├── MarketAnalyzer — aggregated demand patterns
├── CreditScorer — Alama Score (300-850)
├── FederatedAggregator — privacy-preserving model updates
├── DifferentialPrivacyEngine — ε=0.1 noise injection
├── kAnonymityEnforcer — k≥10 cohort enforcement
├── SyncReceiver — device data reception
├── ReportEngine — business/intelligence reports
├── APIGateway — REST API for external buyers
└── ... (12 more tools)
```

**Tech Stack:** Rust (Axum + Tokio) • PostgreSQL 16 • ClickHouse 24 • Redis 7 • Docker
